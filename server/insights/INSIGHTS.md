## Tool & Library Notes

2026-10-24 — `AgentState.lastSessionId` / `pausedAfterRelease` have no `agents` column: AgentsRepository derives them on read (newest session by number; `agent_sim_state.pending_refusal_ticket_id IS NOT NULL`) and ignores them on update. ref: server/src/infrastructure/repositories/agents.repository.ts:1

2026-10-24 — `tsconfig.json` includes `vitest.config.ts`, so config type errors surface in `pnpm typecheck`, not in `vitest run`. ref: server/tsconfig.json:5

2026-10-24 — Server lock uses a dedicated `pg.Client` (not the pool) so the session-level advisory lock lives for the process lifetime; the reset probe does try-lock + immediate unlock. Verified against live Postgres. ref: server/src/infrastructure/db/server-lock.ts:1

2026-10-24 — drizzle migrator errors do not name the migration; `runMigrations` reads applied-count from `drizzle.__drizzle_migrations` before running and indexes `meta/_journal.json` (migrations run in one transaction, so count-before = failing index). ref: server/src/infrastructure/db/migrate.ts:25

2026-10-24 — Fixture is generated by evaluating the prototype's `class Component` in an empty `node:vm` context (stub `DCLogic`, JSON round-trip out of the foreign realm); golden numbers (121 sessions, 1 918 entries, $305.19, 44 events) matched on the first run, `--check` also diffs against the committed JSON. Prices are decimal strings; cost totals use BigInt (price x100). ref: server/scripts/generate-fixture.ts:1

## Recurring Errors & Fixes

2026-10-24 — The T11 acceptance grep `grep "from '@agent-ops/shared'" | grep -v "import type"` is line-based, so Prettier-wrapped multi-line `import type { … }` blocks fail it; domain files use `import type * as S from '@agent-ops/shared'` when the name list would wrap. ref: server/src/domain/event-builders.ts:1

## Open Questions

2026-10-24 — Circular FKs (tickets<->agents<->sessions) via table-level `foreignKey({name,...})` make TS infer `any` (TS7022/7024); annotate every extra-config callback `(t): PgTableExtraConfigValue[] => [...]`. Inline `.references()` cannot be named, hence table-level. ref: server/src/infrastructure/db/schema.ts:60

2026-10-24 — pg "client.query() already executing" came from use cases doing `Promise.all` over reads that share one snapshot-tx connection; fixed by queueing all ReadQueries/journal calls in PgSnapshotReader. ref: src/infrastructure/db/snapshot.ts:14

2026-10-24 — In drizzle `sql` templates a `\S` is cooked to `S`; write `'\\S'` in schema.ts so the migration contains `'\S'`. Session-level advisory lock dies with its connection, so server-lock.ts re-acquires on a new connection and fires `onTaken` (main.ts exits 1) if another process won. ref: src/infrastructure/db/server-lock.ts:30
